CHOIS 개인정보처리방침

시행일: 2026년 10월 31일

CHOIS는 주식회사 에르메스투어 대표가 본인 업무에만 쓰는 업무 비서입니다. 이 방침은 CHOIS가 Google 계정에서 받는 정보를 어떻게 다루는지 설명합니다.

1. 누가 쓰나요

CHOIS에 Google 계정을 연결하는 사람은 에르메스투어 대표 본인뿐입니다. 다른 사람에게 서비스하지 않습니다.

2. 어떤 정보에 접근하나요

  • Gmail: 메일 읽기, 정리(라벨·읽음 표시), 보내기
  • Google 캘린더: 일정 보기, 만들기, 고치기
  • Google 드라이브, 문서, 시트: 파일 찾기, 읽기, 만들기, 고치기
  • Google 연락처: 읽기만

3. 어디에 쓰나요

대표가 요청한 업무(메일 정리, 답장 초안, 일정 확인, 문서 작성)를 처리하는 데만 씁니다. 광고, 판매, 신용 평가, 다른 목적의 분석에는 쓰지 않습니다.

4. 어디에 저장되나요

Google 로그인 정보(토큰)는 대표의 컴퓨터 안에만 저장됩니다. 가져온 메일과 파일 내용은 그 컴퓨터에서 처리하며 별도 서버에 모아 두지 않습니다. 처리에는 그 컴퓨터에서 돌아가는 인공지능 모델을 씁니다. 그 모델이 멈췄을 때만 대표 본인 계정의 외부 인공지능 서비스가 대신 처리할 수 있습니다.

5. 다른 곳에 넘기나요

Google 사용자 데이터를 제3자에게 팔거나 넘기지 않습니다. 사람이 이 데이터를 열람하는 일은 대표 본인뿐입니다.

6. Google API 서비스 사용자 데이터 정책

CHOIS가 Google API에서 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

7. 연결 끊기와 삭제

Google 계정 → 보안 → 타사 앱 액세스에서 언제든 CHOIS의 접근 권한을 취소할 수 있습니다. 취소하면 컴퓨터에 저장된 로그인 정보도 지웁니다.
